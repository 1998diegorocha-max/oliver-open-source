# Contributing

Thank you for helping make the public project clearer and more useful. English and Brazilian Portuguese contributions are welcome.

## Current stage

This checkout contains documentation and templates. There is no package to install, public runtime to start or automated software test command yet. The [roadmap](docs/ROADMAP.md) defines the first technical release.

Useful contributions include a small component proposal, corrections to documentation, reproducible test scenarios, accessibility feedback and dependency or license research with primary sources.

## A useful proposal

Describe the problem, who would benefit, the smallest useful change and how another person could verify it. Include hardware and cost constraints when relevant. Discuss substantial changes before preparing a large pull request.

For future code contributions, include setup instructions, relevant tests, limitations and dependency licenses. Report failures as well as successful checks. Distinguish a simulation from a real-device test.

## Review and publication

Use a focused branch and explain the final change in the pull request. Preserve the license and existing public history. New public files must be reviewed for credentials, private endpoints, personal information and material that cannot be redistributed.

Private product code, logs, recordings, keys and owner data must not be copied into this repository as part of a documentation contribution. Follow [SECURITY.md](SECURITY.md) for sensitive findings.
